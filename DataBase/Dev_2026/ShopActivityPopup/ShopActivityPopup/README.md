# ShopActivityPopup

Windowsのタスクトレイに常駐し、キーボード入力またはマウス移動を検知すると、画面中央に指定URLを表示するWPFアプリです。

## 設定画面と管理者認証

設定画面を開く方法は**Ctrl+Sだけ**です。タスクトレイメニュー、ポップアップ画面、サイト画面には設定メニューや歯車ボタンを用意していません。

Ctrl+Sを押すと、Windows標準のUAC（ユーザーアカウント制御）を使って管理者資格情報を要求します。アプリが管理者権限で起動していない場合、設定画面だけを別プロセスとして`runas`起動します。アプリ自身が管理者パスワードを取得、保存、送信することはありません。UACでキャンセルした場合、設定は変更されず、通常の待機監視に戻ります。

管理者用の設定プロセスには通常の常駐処理を開始しない`--settings`引数を使用しています。設定保存後、設定画面と表示中のサイトは閉じ、元のアプリは待機状態に戻ります。

設定項目は、表示URL、画面幅（px）、画面高さ（px）、無操作で閉じるまでの秒数です。URLはhttpまたはhttpsだけを受け付けます。

## 表示画面

表示ウィンドウはタイトルバーと上部バーを持たず、丸みを帯びた四角形です。戻る・進むボタンはサイト画面上部左側に浮かぶ独立した島として表示し、閉じるボタンは同じ高さの独立した島として右上に表示します。サイト以外の表示要素はこの3個のボタンだけです。WebView2内のサイトは通常どおりユーザーが操作できます。

サイト表示中は、初期値で180秒（3分）連続して操作がなければ自動的に閉じて待機モードへ戻ります。閉じるボタンを押した場合はサイトだけを閉じ、アプリは終了しません。その後30秒間連続して操作がない間は再表示を抑止し、30秒経過後に通常の入力待機へ戻ります。

幅と高さの初期値は0で、表示時にメインディスプレイの作業領域の80%を使用します。

## 必要環境とビルド

Windows 10/11、.NET 8 SDK、Microsoft Edge WebView2 Runtimeが必要です。

```powershell
dotnet restore
dotnet build -c Release
dotnet run
```

WebView2パッケージを手動で導入する場合は次のコマンドです。

```powershell
dotnet add package Microsoft.Web.WebView2 --version 1.0.2903.40
dotnet restore
```

## exe発行

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -o .\publish\win-x64
```

`publish\win-x64\ShopActivityPopup.exe`と`appsettings.json`を同じフォルダーで配布します。WebView2 Runtimeは別途必要です。

## セキュリティと店頭運用

グローバルフックは入力監視に似て見えるため、コード署名証明書でexeとインストーラーに署名し、取得しているのは入力イベントの発生だけで、キー内容・マウス座標・クリップボード・画面キャプチャを取得しないことを利用者向けに明示してください。設定ファイルは一般ユーザーが書き換えられない場所に置き、管理下のHTTPSサイトだけを表示対象にしてください。店頭端末では、専用標準ユーザー、Windows Update、WebView2更新、セキュリティ製品による事前検査も実施してください。
