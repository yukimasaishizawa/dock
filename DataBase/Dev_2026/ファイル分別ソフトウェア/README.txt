ファイル・エキスplorer（File Explorer）
============================

【機能】
  - 指定フォルダ内のファイルを拡張子ごとに自動整理表示
  - 拡張子・ファイル数・ファイルサイズの表示
  - 色分け機能（「拡張子色」でファイルタイプごとに色分け、「色パターン」で交互に白黒）
  - 検索機能（ファイル名・拡張子のどちらにキーワードが含まれていれば検索）
  - CSV エクスポート（拡張子ごとのファイル数とサイズ合計）
  - クリア機能（一覧をリセット）

【実行方法】
  1. Terminal を開く
  2. 以下のコマンドを実行
     python3 file_explorer/main.py
  3. アプリが起動したら、"フォルダを選択"ボタンをクリック
  4. 分析対象のフォルダを選択

【使用前提】
  - Python 3.8 以上
  - PySide6（pip install PySide6）
  - macOS での実行想定

【表示形式】
  - 表形式で、以下の項目が表示されます：
    1. 拡張子（例：.py, .txt, .md など）
    2. ファイル数（該拡張子のファイル数）
    3. ファイルサイズ合計（KB/MB/GB 自動変換）
    4. ファイル名一覧（ファイル名 (サイズ) の形式）

【色分けモード】
  - 「無効」：標準の白黒表示
  - 「拡張子色」：ファイルタイプごとに色分け（Python=緑、JavaScript=紫など）
  - 「色パターン」：行を交互に白黒で表示

【検索機能】
  - 検索キーワードを記入
  - 検索すると、ファイル名または拡張子にキーワードが含まれるファイルのみが表示されます
  - 再表示するには「一覧を表示」ボタンを押します

【注意事項】
  - 対象フォルダは Python が読める権限が必要です
  - 極端に大きなフォルダ（数 TB）は動作が重くなる可能性があります
  - Sublimetext フォーマットではありませんが、ファイル管理アプリとして使用できます
  - 拡張子「no extension」は、拡張子のないファイルがまとまるグループです

【サポート拡張子（色分け時）】
  - 画像：.png, .jpg, .jpeg
  - テキスト：.txt, .md, .csv, .json
  - スクリプト：.py, .js, .java, .c, .cpp
  - Web：.html, .htm, .css
  - ドキュメント：.pdf, .doc, .docx
  - プレゼン：.ppt, .pptx
  - プリンター：.psd, .ai
  - その他：.xml, .zip, .rar, .gz など
